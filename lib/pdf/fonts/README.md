# Fuentes embebidas en los PDF

TTF completos (con griego: el COA necesita "Δ" para Δ-8-THC / Δ-9-THC).

| Archivo                             | Familia | Uso en el COA                | Licencia                  |
| ----------------------------------- | ------- | ---------------------------- | ------------------------- |
| Chivo-Regular.ttf, Chivo-Bold.ttf   | Chivo   | títulos, etiquetas, tablas   | SIL Open Font License 1.1 |
| Roboto-Regular.ttf, Roboto-Bold.ttf | Roboto  | notas al pie, disclaimer FDA | Apache License 2.0        |

Origen: Google Fonts (vía los paquetes `@expo-google-fonts/*`, que traen los TTF sin subsetear).
Se versionan en el repo para que generar un PDF no dependa de la red.
